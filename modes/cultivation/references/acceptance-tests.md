# Acceptance tests

## Static integrity

- Every JSON parses and every foreign key resolves.
- Stable IDs and names are unique.
- Old IDs remain unchanged unless a declared migration updates them.
- Exact net-new counts and distributions match the contract.
- Composite character fingerprints do not duplicate canon.

## Context behavior

Test an ordinary local scene, entering a faction region, returning and unloading remote actors, a 12-person meeting, a request above the 20-person cap, remote fame through rumor, and public packets scanned for secrets or GM truth.

## Simulation

Use multiple deterministic seeds at 50, 100, and 300 years. Record deaths, breakthroughs, failed paths, marriage, discipleship, office, succession, faction change, techniques, fame, fade, and high-tier counts. Require matrix diversity, not identical outcomes in every seed. Reject universal success, universal survival, plot armor, and high-tier inflation.

## Packaging

Run project-native tests, compare PNG card metadata with JSON, check lore budget and selective flags, validate bridge security, generate SHA-256 integrity, test ZIP CRC, and list pending human gates.
