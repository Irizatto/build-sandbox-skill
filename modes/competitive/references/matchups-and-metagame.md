# Matchups and metagame

## Conditional relation

Represent each estimate with subject, object or composition, relation type, ruleset version, roles, map or side, game phase, allied context, opposing context, participant proficiency, evidence, sample scope, confidence, uncertainty, timestamp, and expiration.

## Evidence classes

Keep official rules, direct observations, aggregate statistics, controlled tests, expert judgments, model estimates, team beliefs, and public narratives distinct. Conflicting evidence remains visible and weighted; do not silently collapse it into one number.

## Hypergraph effects

Use hyperedges for composition structures involving multiple selections, role flexibility, chained synergies, denial value, or strategic packages. Preserve explanations for why an edge applies and when it stops applying.

## Version changes

Patch or ruleset changes invalidate or decay affected edges. Never apply an old estimate merely because entity names still match. Historical analysis pins the old version; current recommendation uses the declared current version.
